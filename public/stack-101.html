Hosting & Domains — Where your apps live on the internet

These services take your code and make it accessible at a URL. You push code, they publish it.

🚀
Render $7/mo Starter
Full-stack app hosting
Hosts your entire app — both the website visitors see AND the server code that powers it (API routes, chat logic, database calls). You push code to GitHub, Render automatically rebuilds and publishes it.
💡 Think of it as: renting a small shop space where your app lives and runs 24/7
WelcomeMatSwoop
🔗 dashboard.render.com
▲
Vercel Free tier
Static site hosting
Hosts websites that don't need a backend server — just HTML, CSS, and JavaScript files. Lightning fast, globally distributed. Great for personal sites and simple web apps. Also auto-deploys from GitHub.
💡 Think of it as: a billboard company that puts your poster up worldwide in seconds
Personal SiteTuckKoloHomeOps HubProject Cushion
🔗 vercel.com/dashboard
☁️
Cloudflare ~$10/yr per domain
Domain registrar + DNS + security
Where you buy and manage domain names (like welcomematdigital.com). Also handles DNS — the system that translates "welcomematdigital.com" into the actual server address. Adds speed and security for free on top.
💡 Think of it as: buying your store's street address AND getting a free security guard at the door
WelcomeMatPersonal Site
🔗 dash.cloudflare.com
🏷️
Namecheap ~$9-13/yr per domain
Domain registrar
Another popular place to buy domain names. Simple interface, competitive pricing, includes free WhoisGuard privacy protection. Some of your older domains may be registered here.
💡 Think of it as: a different real estate office for buying web addresses — same result, different storefront
Personal Site
🔗 namecheap.com/myaccount

🎯 When to use what

  • Need a backend server (API, database, chat logic)? → Render
  • Just HTML/CSS/JS files (no server needed)? → Vercel
  • Buying a new domain? → Cloudflare (cheapest at-cost pricing, built-in DNS + CDN)
  • Already have a Namecheap domain? → Keep it there, just point DNS to Cloudflare for free speed/security

Databases — Where your data lives

Every app needs to store information somewhere — user accounts, chat messages, business details. Databases are that "somewhere."

🗄️
Turso Free tier
Lightweight cloud database
A SQLite database that lives in the cloud. Stores WelcomeMat's business info, chat conversations, admin accounts, and site settings. Super fast, super cheap — free tier covers thousands of businesses.
💡 Think of it as: a spreadsheet in the cloud that your app reads and writes to, but way faster
WelcomeMat
🔗 app.turso.tech
⚡
Supabase Free tier
Database + auth + storage (all-in-one)
A more full-featured database (PostgreSQL) that also handles user login/signup and file storage. You get a database, authentication, and file uploads without building any of that yourself.
💡 Think of it as: Turso's bigger sibling that also handles passwords and file uploads
Kolo
🔗 supabase.com/dashboard

When do I use which?

TursoSupabase
TypeSQLite (simple, lightweight)PostgreSQL (full-featured)
ExtrasJust the databaseAuth + file storage + realtime
Best forSimple apps, tight budgetApps with user login / file uploads
Rule of thumbNeed just data storage? → Turso. Need login + permissions + storage? → Supabase.

🎯 When to use what

  • Simple app, just storing data (business info, chat logs)? → Turso
  • Need user accounts + login (family members, team access)? → Supabase
  • Need file uploads (photos, documents)? → Supabase (has built-in storage)
  • Budget is tight? → Both have generous free tiers, but Turso's is simpler to stay within

Communication — Texts & calls from your app

These services let your code send real text messages and make phone calls — no human needed.

📱
Twilio Pay per use
Send/receive SMS and calls from code
Lets your app send text messages and make phone calls programmatically. When someone misses a call (Swoop), Twilio detects it and sends an AI-crafted text back automatically. ~$1/mo per phone number + pennies per text.
💡 Think of it as: your app's own phone line — it can text and call people on your behalf
Swoop
🔗 console.twilio.com
💬
Vonage (Nexmo) Pay per use
Twilio alternative — SMS, voice, verify
Very similar to Twilio — send/receive SMS and calls programmatically. Generally easier number verification process, slightly cheaper SMS rates. Good Node.js SDK. Worth trying if Twilio's verification is blocking you.
💡 Think of it as: the other phone company — same service, less red tape to get started
Plan B for Swoop
🔗 dashboard.vonage.com
📞
Plivo Pay per use
Budget-friendly SMS & voice API
Another Twilio competitor. ~30-40% cheaper on SMS, simpler pricing, less strict number verification. Smaller ecosystem than Twilio but solid for SMS + voice. Good if cost is a concern at scale.
💡 Think of it as: the budget airline of telecom APIs — gets you there for less, fewer frills
Plan B for Swoop
🔗 console.plivo.com
✉️
Telnyx Pay per use
Developer-first telecom with own network
Runs its own carrier network (not reselling like most). Very competitive pricing, fast number provisioning, mission-control style dashboard. Gaining popularity as the "modern Twilio alternative."
💡 Think of it as: the indie carrier that built its own cell towers — cheaper and faster because there's no middleman
Plan B for Swoop
🔗 portal.telnyx.com

🎯 When to use what

  • Already working and verified? → Stay on Twilio (largest ecosystem, most tutorials/support)
  • Stuck on Twilio number verification? → Try Vonage first (easiest migration, similar API)
  • Want cheapest SMS at scale? → Plivo (30-40% cheaper per text than Twilio)
  • Want a modern, developer-friendly option? → Telnyx (own network, fast setup, growing fast)
  • Just need email notifications? → Skip all of these, use Resend or SendGrid (free tier)
  • Building a missed-call product? → Any of these + OpenAI combo (Swoop pattern)

Dev Tools — Your workshop

The tools you use every day to write, manage, and run code. All free.

🐙
GitHub Free
Code storage + version control
Where all your code lives online. Every project is a "repository" (repo). Tracks every change you've ever made so you can undo anything. Also triggers auto-deploys to Render/Vercel when you push code.
💡 Think of it as: Google Drive for code, but with infinite undo history and auto-publishing
All projects
🔗 github.com/sunilmsft
💻
VS Code Free
Code editor
The app on your computer where you actually write and edit code. Comes with a built-in terminal (command line), file explorer, and tons of extensions. Made by Microsoft — same place Copilot lives.
💡 Think of it as: Microsoft Word, but for writing code instead of documents
All projects
📦
npm Free
JavaScript package manager
An app store for code libraries. Instead of writing everything from scratch, you "install" pre-built packages. For example: npm install openai gives you all the code needed to talk to OpenAI in one command.
💡 Think of it as: an app store where every app is a pre-built Lego block you can snap into your project
All projects
🟢
Node.js Free
Run JavaScript on servers
JavaScript was originally only for browsers. Node.js lets you run JavaScript on a server — which is how WelcomeMat's backend works. Your chat API, database calls, and admin routes all run on Node.js.
💡 Think of it as: the engine under the hood that lets your server code actually run
WelcomeMatSwoop

🎯 When to use what

  • Writing any code? → VS Code (always)
  • Need to save/share code or trigger deploys? → GitHub (always)
  • Adding a library or SDK? → npm install [package] in terminal
  • App needs a backend server? → You're writing Node.js code
  • App is frontend-only? → You don't need Node.js at all — just HTML/CSS/JS
