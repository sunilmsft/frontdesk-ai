Hosting & Deployment — Where your apps live

🚀
Render $7/mo Starter
Full-stack app hosting
Hosts your entire app — both the website visitors see AND the server code that powers it (API routes, chat logic, database calls). You push code to GitHub, Render automatically rebuilds and publishes it.
💡 Think of it as: renting a small shop space where your app lives and runs 24/7
WelcomeMat Swoop
▲
Vercel Free tier
Static site hosting
Hosts websites that don't need a backend server — just HTML, CSS, and JavaScript files. Lightning fast, globally distributed. Great for personal sites and simple web apps. Also auto-deploys from GitHub.
💡 Think of it as: a billboard company that puts your poster up worldwide in seconds

Domains & DNS — Your addresses on the internet

☁️
Cloudflare ~$10/yr per domain
Domain registrar + DNS + security
Where you buy and manage domain names (like welcomematdigital.com). Also handles DNS — the system that translates "welcomematdigital.com" into the actual server address. Adds speed and security for free on top.
💡 Think of it as: buying your store's street address AND getting a free security guard at the door
WelcomeMat Personal Site

Databases — Where your data lives

🗄️
Turso Free tier
Lightweight cloud database
A SQLite database that lives in the cloud. Stores WelcomeMat's business info, chat conversations, admin accounts, and site settings. Super fast, super cheap — free tier covers thousands of businesses.
💡 Think of it as: a spreadsheet in the cloud that your app reads and writes to, but way faster
WelcomeMat
⚡
Supabase Free tier
Database + auth + storage (all-in-one)
A more full-featured database (PostgreSQL) that also handles user login/signup and file storage. You get a database, authentication, and file uploads without building any of that yourself.
💡 Think of it as: Turso's bigger sibling that also handles passwords and file uploads
Kolo

AI & Intelligence — The brains

🧠
OpenAI API Pay per use
AI that reads, writes, and thinks
The engine behind your AI chat widgets. Your app sends a question + context to OpenAI, it sends back a smart answer. Uses GPT-4o-mini (~$0.50/mo per business). Also powers DALL-E for generating logos.
💡 Think of it as: hiring a genius receptionist who never sleeps, and you pay per conversation
WelcomeMat Swoop
🎨
DALL-E ~$0.04/image
AI image generation
Part of OpenAI. Generates logos and images from text descriptions. You describe what you want ("a cleaning company logo with a camellia flower") and it creates it. Used during WelcomeMat site builds.
💡 Think of it as: a graphic designer who works in 10 seconds for 4 cents
WelcomeMat
🤖
GitHub Copilot Free (MSFT benefit)
AI coding assistant
Lives inside VS Code and helps you write code. Autocompletes lines, writes functions, explains errors, and builds entire features from descriptions. This is what you're talking to right now.
💡 Think of it as: a pair programmer sitting next to you who's read every coding tutorial ever

Communication — Texts & calls

📱
Twilio Pay per use
Send/receive SMS and calls from code
Lets your app send text messages and make phone calls programmatically. When someone misses a call (Swoop), Twilio detects it and sends an AI-crafted text back automatically. ~$1/mo per phone number + pennies per text.
💡 Think of it as: your app's own phone line — it can text and call people on your behalf
Swoop

Dev Tools — Your workshop

🐙
GitHub Free
Code storage + version control
Where all your code lives online. Every project is a "repository" (repo). Tracks every change you've ever made so you can undo anything. Also triggers auto-deploys to Render/Vercel when you push code.
💡 Think of it as: Google Drive for code, but with infinite undo history and auto-publishing
All projects
💻
VS Code Free
Code editor
The app on your computer where you actually write and edit code. Comes with a built-in terminal (command line), file explorer, and tons of extensions. Made by Microsoft — same place Copilot lives.
💡 Think of it as: Microsoft Word, but for writing code instead of documents
All projects
📦
npm Free
JavaScript package manager
An app store for code libraries. Instead of writing everything from scratch, you "install" pre-built packages. For example: npm install openai gives you all the code needed to talk to OpenAI in one command.
💡 Think of it as: an app store where every app is a pre-built Lego block you can snap into your project
All projects
🟢
Node.js Free
Run JavaScript on servers
JavaScript was originally only for browsers. Node.js lets you run JavaScript on a server — which is how WelcomeMat's backend works. Your chat API, database calls, and admin routes all run on Node.js.
💡 Think of it as: the engine under the hood that lets your server code actually run
WelcomeMat Swoop

Wait, when do I use Render vs Vercel?

Render Vercel
Best for Apps with a backend server Static sites / frontend only
Example WelcomeMat (has API + DB) Personal site, Kolo, Tuck
Think of it as Rent a small server Free billboard space
Rule of thumb Does it need a server running 24/7? → Render. Is it just HTML/CSS/JS files? → Vercel.

Turso vs Supabase — which database when?

Turso Supabase
Type SQLite (simple, lightweight) PostgreSQL (full-featured)
Extras Just the database Auth + file storage + realtime
Best for Simple apps, tight budget Apps with user login / file uploads
Rule of thumb Need just data storage? → Turso. Need login + permissions + storage? → Supabase.
